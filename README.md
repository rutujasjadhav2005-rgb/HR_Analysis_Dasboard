# HR Analysis Dashboard | Power BI

## 📌 Project Overview

The **HR Analysis Dashboard** is a Power BI project designed to analyze Human Resources (HR) data and present key insights through interactive visualizations. It helps understand employee-related information and supports data-driven HR decision-making.

## 🎯 Project Objectives

* Analyze HR data to identify meaningful insights.
* Track key employee-related metrics and trends.
* Present HR information using interactive dashboards.
* Support better workforce planning and decision-making.

## 🛠️ Tech Stack

* **Microsoft Power BI** – Dashboard development and data visualization
* **Power Query** – Data cleaning and transformation
* **DAX** – Calculations and measures
* **Microsoft Excel** – Data source and data preparation (if applicable)

## 📊 Key Features

* Interactive HR dashboard
* Visual representation of HR metrics
* Employee data analysis
* HR trends and performance insights
* User-friendly dashboard for data-driven decisions

## 🚀 How to Use

1. Download or clone this repository.
2. Install Microsoft Power BI Desktop.
3. Download the `.pbix` file from this repository.
4. Open the file in Power BI Desktop.
5. Explore the dashboard and interact with the available visualizations and filters.

## 💡 Business Benefits

* Helps HR teams understand employee data.
* Makes HR reporting easier and more interactive.
* Supports workforce analysis and planning.
* Converts raw data into meaningful visual insights.
